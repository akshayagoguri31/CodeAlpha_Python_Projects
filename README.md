# CodeAlpha Python Projects

This repository contains Python projects completed during my CodeAlpha internship.

## Projects

### 1. Hangman Game
A simple console-based Hangman game developed using Python.

**Features:**
- Random word selection
- Letter-by-letter guessing
- Limited incorrect guesses
- Displays the current word progress

**File:** `hangman.py`

### 2. Basic Chatbot
A simple rule-based chatbot developed using Python.

**Features:**
- Responds to basic user greetings and questions
- Interactive command-line conversation
- Exit option using `bye`

**File:** `chatbot.py`

### 3. Stock Portfolio Tracker
A simple Python-based stock portfolio tracker.

**Features:**
- Accepts stock symbols
- Accepts stock quantities
- Calculates investment value
- Calculates total investment value

**File:** `portfolio.py`

## Technologies Used

- Python
- Python Standard Library
- Command Line Interface (CLI)
